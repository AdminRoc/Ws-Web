# Map Assets

This directory contains map background images used by the interactive map.

## Required Images

Download the following 4K map images from Warframe Wiki and save them here:

| File Name | Source | Wiki Page |
|-----------|--------|-----------|
| `duviri-map.png` | Duviri Map | https://wiki.warframe.com/w/Duviri/Map |
| `plains-of-eidolon-map.png` | Plains of Eidolon Map | https://wiki.warframe.com/w/Plains_of_Eidolon/Map |
| `orb-vallis-map.png` | Orb Vallis Map | https://wiki.warframe.com/w/Orb_Vallis/Map |
| `cambion-drift-map.png` | Cambion Drift Map | https://wiki.warframe.com/w/Cambion_Drift/Map |

## Notes

- All images should be 4000x4000 pixels (or close to it)
- Format: PNG with transparency support
- These images are sourced from the official Warframe Wiki under their content license
